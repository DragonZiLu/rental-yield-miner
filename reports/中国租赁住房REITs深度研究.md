# 中国租赁住房 REITs 深度研究

> 生成时间: 2026-06-15 | 数据来源: 各REIT年报/季报 + 交易所公告 | 用途: 教育研究，非投资建议

---

## 一、市场概览

中国基础设施公募 REITs 自 2021 年首批上市，租赁住房类是2022年才开辟的新赛道。目前全市场 5 只，总规模约 **400 亿**，资产全部集中在一线城市。

### 为什么租赁住房 REITs 值得关注

| 优势 | 说明 |
|------|------|
| **天然垄断** | 一线城市核心地段土地不可再生，租赁住房供给受限 |
| **需求刚性** | 城镇化+人口向一线聚集，租房是刚需 |
| **抗周期** | 经济下行时反而更多人租房（买房推迟） |
| **政策背书** | 国家推动"租购并举"，REITs 是重要金融工具 |
| **强制分红** | 监管要求分配 90%+ 可分配收入，现金流稳定 |

### 和直接买房的区别

| 维度 | 直接买房收租 | 买 REITs |
|------|-------------|----------|
| 门槛 | 45-250 万 | 1,000 元起 |
| 回报率 | 4.0-4.5%（个人经营者） | 3.5-4.2%（机构批量化） |
| 流动性 | 极差（卖房 3-6 月） | 好（T+1 交易） |
| 杠杆 | 可贷款（首付 15-30%） | 不可 |
| 管理 | 自己管/中介 | 华润/万科/城投 专业运营 |
| 分散度 | 单城单小区 | 一篮子资产 |
| 税费 | 契税+增值税+个税 | 免印花税、分红个税优惠 |

> **关键结论**：REITs 收益率略低于自己经营（约差 0.3-0.5%），但省去了全部管理成本和空置风险。**流动性+专业化 > 0.3% 的收益率差异。**

## 二、五只 REITs 逐一拆解

### 2.1 华夏华润有巢 REIT（508077）

| 维度 | 详情 |
|------|------|
| **全称** | 华夏华润有巢租赁住房封闭式基础设施证券投资基金 |
| **上市日** | 2022-12-09 |
| **原始权益人** | 华润置地（央企） |
| **底层资产** | 上海：有巢泗泾项目（松江）+ 有巢东部经开区项目 |
| **房间数** | 约 2,600 间（2025扩张后） |
| **资产类型** | **唯一市场化租赁住房**（非保租房/非公租） |
| **租金定价** | 随行就市，不受政府限价 |
| **出租率** | ~93%（市场化正常波动，保租房通常 98%+） |
| **年化分红率** | **~4.2%**（五只最高） |
| **2024 营收** | ~1.8 亿 |
| **2024 净利** | ~4,000 万（扣除折旧摊销后） |
| **资产估值** | ~15 亿（上市初），2025 扩募后更高 |
| **扩募计划** | 2025年新增北京、上海项目 |
| **清算年限** | 50 年（土地使用权到期日） |

**优势**：
- ✅ 唯一市场化定价 — 如果租金通胀来了，它是唯一受益者
- ✅ 华润置地央企背景，运营能力强
- ✅ 持续扩募（从上海扩到北京）
- ✅ 分红率最高

**风险**：
- ⚠️ 保障房大量入市可能压制市场化租金（尤其上海"十四五"计划新增 47 万套保租房）
- ⚠️ 出租率 93% 低于保租房（保租房通常有政府配租，不愁租客）
- ⚠️ 集中在上海（单城市风险）
- ⚠️ 资产在松江而非核心区，区位溢价有限

**和我们分析的对标**：
```
华润有巢分红率 4.2%
上海住宅自购租售比（我们估算）: 4.0-4.1%
→ 华润有巢略高于自购，体现机构化运营的效率优势
```

### 2.2 国泰君安城投宽庭 REIT（508031）

| 维度 | 详情 |
|------|------|
| **全称** | 国泰君安城投宽庭保障性租赁住房 REIT |
| **上市日** | 2024-01-12 |
| **原始权益人** | 上海城投（地方国企） |
| **底层资产** | 上海：江湾社区（杨浦）+ 光华社区（闵行） |
| **房间数** | ~3,000 间 |
| **资产类型** | 保障性租赁住房 |
| **租金定价** | 政府指导价，不高于同地段市场化租金 90% |
| **出租率** | ~95%（上市首年） |
| **年化分红率** | **~3.9%** |
| **2024 营收** | ~2.2 亿（规模大于有巢） |
| **2024 净利** | ~7,000 万 |
| **资产估值** | ~32 亿（上市初，五只最大） |
| **扩募计划** | 上海城投资产储备充足（多个保租房项目在建） |
| **清算年限** | 50 年 |

**优势**：
- ✅ 资产规模最大（32 亿），流动性相对最好
- ✅ 上海城投国企背景，政策资源强
- ✅ 杨浦区项目靠近复旦/同济，区位优于松江
- ✅ 上市晚，定价更合理（2024年市场定价理性）

**风险**：
- ⚠️ 保租房属性意味着租金涨幅受限
- ⚠️ 仅上海单一城市
- ⚠️ 分红记录仅 1 年，可参考性弱于老 REITs

**判断**：
> 价格合理 + 资产好 + 分红中上。作为「次新 REITs」性价比最高。

### 2.3 中金厦门安居 REIT（508058）

| 维度 | 详情 |
|------|------|
| **全称** | 中金厦门安居保障性租赁住房 REIT |
| **上市日** | 2022-08-31 |
| **原始权益人** | 厦门安居集团（地方国企） |
| **底层资产** | 厦门：园博公寓（集美）+ 珩琦公寓（集美） |
| **房间数** | ~4,600 间（2025扩募后） |
| **资产类型** | 保障性租赁住房 |
| **租金定价** | 政府指导价，面向新市民/青年人 |
| **出租率** | **99.5%** — 五只最高，几乎满租 |
| **年化分红率** | **~3.8%** |
| **2024 营收** | ~1.1 亿 |
| **2024 净利** | ~3,500 万 |
| **资产估值** | ~12 亿（上市初） |
| **扩募计划** | 2025年完成首批扩募，新增两个项目 |
| **清算年限** | 50 年 |

**优势**：
- ✅ 出租率 99.5% 冠绝全场，几乎无空置风险
- ✅ 厦门岛内供给极度稀缺，价格有天然支撑
- ✅ 2025 年成功扩募，管理层执行力验证
- ✅ 集美区有厦门理工/集美大学/华侨大学，学生溢出租赁需求

**风险**：
- ⚠️ 厦门城市量级远不如北上深，资产天花板低
- ⚠️ 厦门人口增速放缓
- ⚠️ 分红率 3.8% 处于中游，不算突出

**判断**：
> 小而稳，适合「求稳不求增长」的保守型。厦门岛内土地稀缺是最大护城河。

### 2.4 红土创新深圳安居 REIT（180501）

| 维度 | 详情 |
|------|------|
| **全称** | 红土创新深圳人才安居 REIT |
| **上市日** | 2022-08-31（首批三只之一） |
| **原始权益人** | 深圳人才安居集团（深圳国资） |
| **底层资产** | 深圳：安居百泉阁（福田）+ 安居锦园（罗湖）+ 保利香槟苑（坪山）+ 凤凰公馆（大鹏） |
| **房间数** | ~2,000 间（规模较小） |
| **资产类型** | 保障性租赁住房（人才安居） |
| **租金定价** | 政府定价，约为同地段市场化租金 60% |
| **出租率** | ~99% |
| **年化分红率** | **~3.6%** |
| **2024 营收** | ~1.2 亿 |
| **2024 净利** | ~7,500 万 |
| **资产估值** | ~11 亿（上市初） |
| **清算年限** | 50 年 |

**优势**：
- ✅ 深圳福田/罗湖核心地段，区位最好
- ✅ 出租率极高，几乎不空置
- ✅ 深圳人口净流入持续，租赁需求旺盛

**风险**：
- ⚠️ 租金仅为市场化 60%（政府让利），分红率天花板极低
- ⚠️ **2025年首次分红下降**（季度现金流波动），打破「涨」预期
- ⚠️ 深圳保租房大规模新建，"十四五"计划新增 60 万套 → 潜在供给冲击
- ⚠️ 3.6% 分红率全场最低

**判断**：
> ❌ **不推荐**。区位虽好但租金被严重压制+供给冲击最大，3.6% 的分红缺少吸引力。

### 2.5 华夏北京保障房 REIT（508068）

| 维度 | 详情 |
|------|------|
| **全称** | 华夏北京保障房中心 REIT |
| **上市日** | 2022-08-31（首批三只之一） |
| **原始权益人** | 北京保障房中心（北京国资） |
| **底层资产** | 北京：文龙家园（海淀）+ 熙悦尚郡（朝阳） |
| **房间数** | ~2,100 间 |
| **资产类型** | 公共租赁住房（公租房） |
| **租金定价** | **政府严格定价**，完全无市场化成分 |
| **出租率** | ~97% |
| **年化分红率** | **~3.5%** — 全场最低 |
| **2024 营收** | ~8,000 万 |
| **2024 净利** | ~3,000 万 |
| **资产估值** | ~11.5 亿（上市初） |
| **清算年限** | 50 年 |

**优势**：
- ✅ 海淀区（文龙家园）+ 朝阳区（熙悦尚郡），区位极好
- ✅ 北京核心区住宅土地近乎冻结，新增供给极少
- ✅ 公租房租金超稳定（政府兜底租客）
- ✅ 最安全的 REITs（北京+政府直管+核心地段）

**风险**：
- ⚠️ **租金无任何涨价空间**。公租房面向低收入群体，租金常年不变
- ⚠️ 3.5% 分红率无法抵御通胀
- ⚠️ 北京人口管控政策长期压制租赁需求天花板
- ⚠️ 增长完全依赖扩募，非内生

**判断**：
> ❌ **不推荐**。3.5% 的「债券级回报」买一个「股权级风险」的 REIT，性价比极差。它的唯一价值是「北京资产」，但租客付不起价，资产涨不了租。

## 四、关键风险矩阵

### 4.1 系统性风险（所有 REITs 共有）

| 风险 | 影响 | 严重度 |
|------|------|--------|
| **利率上行** | 无风险利率上升 → REITs 折现率提高 → 价格下跌 | 🔴 高 |
| **保障房冲击** | "十四五"全国计划建 870 万套保租房 → 市场化租金承压 | 🟠 中高 |
| **流动性不足** | 单只 REIT 日均成交仅数百万到数千万，大资金难进出 | 🟡 中 |
| **经济下行** | 租客支付能力下降 → 欠租/退租 → 出租率下滑 | 🟡 中 |
| **政策变动** | 保障房租金指导价调整 / 税惠政策到期 | 🟡 中 |

### 4.2 个股风险

| REIT | 特定风险 |
|------|----------|
| 华润有巢 | 保租房冲击市场化租金；松江区位非核心 |
| 城投宽庭 | 新上市历史短；保租房租金涨幅受限 |
| 厦门安居 | 单一城市（二线）；人口增速放缓 |
| 深圳安居 | 分红已现下降；深圳保租房供应激增 |
| 北京保障房 | 公租房零租金弹性；3.5% 回报太低 |

### 5.2 为什么成都还没有租赁住房 REITs？

```
成渝租赁住房 REIT 在排队中，但面临以下问题：
- 保租房租金低（市场化60-80%），分红率可能不具备吸引力
- 成都住宅价格低 → REITs 资产规模偏小 → 基金管理费占比高
- 预计首只成渝 REIT 分红率约 3.2-3.8%，低于自购租售比
```

**这恰好证明我们之前的结论：成都是更适合「自己买」的城市。**

## 六、操作策略建议

### 场景一：只有 10-50 万，不想折腾

```
配置: 100% REITs
推荐: 华润有巢(508077) 60% + 城投宽庭(508031) 40%
逻辑: 低门槛 + 流动性好 + 不是所有钱都能买房
```

### 场景二：有 100-300 万，愿意管理

```
配置: 成都核心区住宅(60%) + REITs(40%)
推荐: 成都武侯/锦江老小区 ×1套 + 华润有巢 REIT
逻辑: 住宅给杠杆+超额收益，REITs给流动性+分散
```

### 场景三：纯现金流策略，不对赌房价

```
配置: 城投宽庭(508031) 50% + 厦门安居(508058) 50%
逻辑: 出租率 95%+/99.5%，现金流入几乎确定
```

### 场景四：赌租金通胀

```
配置: 华润有巢(508077) 100%
逻辑: 唯一市场化租金 REIT，通胀来了它涨租
风险: 保障房冲击是最大不确定性
```
